# N-Ways Addressing for Gabon: what you need to install.
#
# Python 3.9 or later. The reference engine and its tests
# (engine/reference/ga_engine.py, plate_names.py, test_ga.py), the server
# (server/, python3 -m server) and its tests, and the tools in tools/ use only
# Python's standard library: there is no Python package to install, so
# `pip install -r requirements.txt` installs nothing and that is expected.
#
# The server can also run in Docker (server/Dockerfile, server/docker-compose.yml).
#
# Only to rebuild the data from its sources (tools/prepare-inputs.py,
# tools/build-areas.py, tools/extract-buildings.py, tools/assign-areas.py,
# tools/sort-buildings.py, tools/issue_registry.py, tools/build-register.py,
# tools/paper-stats.py), not to run the engine, the server or use the codes:
#   - the DuckDB command-line tool, 1.1 or later, with its spatial extension,
#     on PATH as `duckdb` (https://duckdb.org/docs/installation; macOS:
#     brew install duckdb); the tools set its memory limit to 3 GB;
#   - osmium (https://osmcode.org/osmium-tool/) for the OpenStreetMap exports;
#   - read access to an N-Ways database (NWAYS_DB) and data folder (NWAYS_ROOT);
#     outside N-Ways, use the published data in registry/ and model/ instead.
